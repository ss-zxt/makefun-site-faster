# makefun-site, faster

A drop-in, dependency-free replacement for makefun-site 1.0.0's `build`: same input, same output
tree, byte for byte — with a compiled template engine, a single-pass Markdown renderer with
run-based escaping, and cached slugs, cards and link resolutions doing the work instead.
